## Not included

- **Icon artwork.** The frontend's icon path data has unresolved provenance (standard EXTRACTION_MATRIX §10, E4) and is not copied. Consumers supply their own icon set through `MarqueeRoot`'s `icons` prop. `scripts/check-artwork.mjs` checks the documentation and the package (one-way hashes of the excluded icons only).
- **Example and test assets.** `examples/config/logo/*.svg` are original synthetic files (copied from Folio's example, itself copied from Console's). The font files under `examples/config/fonts/` are not committed: the example's Vite configuration copies them from the declared `@fontsource-variable/dm-sans` and `@fontsource-variable/manrope` packages (OFL-1.1) when it starts.
- **Development tools** (React, Vite, TypeScript, Playwright, axe-core, Ajv, PostCSS and others) are declared in `package.json` and keep their own licences; they are not shipped in `dist/`. React and React DOM are peer dependencies supplied by the consumer.
